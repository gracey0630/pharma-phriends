# sources and queue (step 10)
Purpose: one gate that every Label Research Agent fetch goes through, so the agent reads only approved sources, and a work queue of the label reads still needed, in the order to do them.

Input:
- `analog_finder/config/approved_sources.yaml` (the approved-source list, docs/data_sources.md)
- `data/processed/`: `analog_features`, `candidate_pool`, `indication_history`; `data/reference/analog_evidence.csv` (every row)
- a scenario (`analog_finder/scenarios/<scenario>.yaml`): its `target` (therapeutic area) and `expected_analogs`
- `.env`: `SEC_USER_AGENT` (needed only to fetch from SEC hosts)

Output ([Shared contracts](../../../docs/implementation_plan.md#shared-contracts)):
- `sources.Gate(...)`: `.check(url, field=None, analog_id=None)` → the matching source (raises `SourceRefused`), `.allowed(...)` → bool, `.filter(urls, field=None, analog_id=None)` → `(kept, dropped)`, `.fetch(url, field=None, *, refresh=False, analog_id=None)` (keyword-only after `field`, since step 11) → `Fetched(url, final_url, path, content_type, redirects)`. `sources.default_gate()` builds one from the repo's config.
- `queue.build_queue(tables, evidence, target=None, expected=(), fields=None, analogs=None)` → work queue table: `priority`, `tier`, `analog_id`, `drug_name`, `application_number`, `orig_application` (the application whose ORIG label to read), `field`, `sources` (approved source names for that field), `status` (`todo` / `pending_review`; an item whose rows were all rejected in review is `todo` again, step 12), sorted by priority then analog then field.
- `python -m analog_finder.research.queue --scenario torevia [--analogs ID ...] [--fields F ...] [--todo-only] [--limit N]` prints it with counts per tier and status.

Depends on: step 1 (`io`); `pipeline.checks.usable` (the usable analogs), `pipeline.build.EVIDENCE_FIELDS`, `pipeline.common` (`RAW`, `USER_AGENT`, `MIN_INTERVAL`, `log_manifest`, `env`).

Decisions made:
- **Hosts match exactly**, case-insensitive, port and trailing dot ignored. A subdomain is allowed only if it's listed itself (`www.sec.gov` doesn't allow `foo.sec.gov`). Only `https` (and `http`, upgraded to `https` before fetching) URLs; anything else, or a URL with a username or password in it, is refused. So is a URL whose path has a `.` or `..` segment (also percent-encoded): the request library would resolve it, so `/h--lundbeck-a-s/../h--other/` would pass a path rule and fetch another company's page. A redirect's `Location` is resolved before it's checked, so it's judged where it lands.
- **What the list allows (checked live 2026-11-19):** every host is a US government site: `www.accessdata.fda.gov` (ORIG label PDFs, Drugs@FDA pages, the REMS list), `www.fda.gov` (Novel Drug Approvals), `clinicaltrials.gov` (API v2), `www.sec.gov` and `efts.sec.gov` (EDGAR filings and full-text search). Each was fetched through the gate without redirects, except SEC, which needs `SEC_USER_AGENT`. `used_for` is checked when the list loads, so a typo (`dosing`) fails instead of silently making a host unusable.
- **Line of therapy only from the ORIG label:** ClinicalTrials.gov was listed for line of therapy, but the plan (step 11), data_model.md and the label-basis decision for targets (decisions.md 2026-11-18) say ORIG label only; a trial's line is where the drug was tested, not what the label requires. It stays on the list for # competitors (same-indication trials).
- **Company sources are tied to their analog and path.** A company's own site is approved only for that company's drug (`analogs`) and only under its part of the site (`paths`), so Lundbeck's page on Cision can't supply another drug's launch date, and other issuers on Cision aren't approved at all. Each was added after reading the launch statement on it (2026-11-19). For Torevia's 5 analogs:
  - **Caplyta, Lybalvi, Vraylar:** their companies are SEC-registered, so launch statements are in 8-K exhibits on `www.sec.gov`, already on the list (Intra-Cellular's Q1 2020 results, 2020-05-07: "Comprehensive promotional activities for CAPLYTA commenced the week of March 30, 2020"; Alkermes' Q3 2021 results; Allergan's Q1 2016 results mention the Vraylar launch, but whether any 8-K gives its date is unchecked). The companies' own sites don't work for the agent: Alkermes' blocks automated requests (403) and Intra-Cellular's IR site is gone since the J&J acquisition (404).
  - **Rexulti:** `news.cision.com` under `/h--lundbeck-a-s/` (Lundbeck's own disclosure channel; Otsuka and Lundbeck aren't SEC-registered). 2016-02-10 results: "Following the launch in the US in August 2015, Rexulti reached DKK 117 million". Month only; the approval release's "early August" is a forecast.
  - **Latuda:** Sumitomo Pharma's IR library (`d145j8vag8dpyh.cloudfront.net/ir/`, the host its site links to; the 2012 annual report is Dainippon Sumitomo's). "LATUDA®, an atypical antipsychotic launched in February 2011". Month only; the exact day (Feb 4) appears only in trade press.
  - **Newswires not added** (Business Wire, PR Newswire, GlobeNewswire): anyone can publish on them, so a path or issuer rule would be needed per company; reprint sites (FiercePharma, BioSpace) are never sources.
- **The queue names the ORIG application.** 45 analogs list several applications in `candidate_pool` (later strengths and forms). `orig_application` comes from `indication_history` (the original ORIG approval); it's the first listed for every current analog, but the rule doesn't depend on the order. `pipeline.labels.orig_label_url` also now finds an original label Drugs@FDA filed under a supplement row (Caplyta: `209500s000lbl.pdf` under SUPPL 1); without that, Caplyta had no label URL. Every usable analog now has one.
- **A field narrows the gate:** with `field=` the host must belong to a source whose `used_for` lists that field, so a press-release host can't be used for dosing. Without it, any listed host passes.
- **Redirects are re-checked.** The gate fetches with redirects off and follows at most 5 by hand, checking each `Location` against the list (with the same field) before requesting it. A redirect to an unlisted host is refused and logged, and nothing from it is saved.
- **Search results are filtered, and what's dropped is logged.** `Gate.filter(urls)` returns the URLs on the list and the ones that aren't; both `filter` and a refused `fetch` append to `data/raw/research/refused.csv` (time, url, field, reason), so the team can see which sites the agent wanted and decide whether to add them.
- **Fetching reuses the pipeline's habits:** about 2 requests a second, retries on 429 / 5xx, the pipeline's `User-Agent` (SEC hosts use `SEC_USER_AGENT` instead and fail with a clear message without it), the file saved unchanged under `data/raw/research/<host>/` and a manifest row per file. Cached: a second fetch of the same URL reads the saved file. `pipeline.common._fetch` follows redirects on its own, so the gate has its own small loop rather than changing the pipeline.
- **Queue pool = the usable analogs** (`pipeline.checks.usable`, 261), not every analog with `enough_data`: a label read only matters to the finder for an analog it can pick. The scenario's expected analogs are always included, even if the funnel drops one. `--analogs` can name any analog in `analog_features`.
- **An (analog, field) is in the queue until it has an approved value.** `status` is `pending_review` when an unapproved row already exists (the agent shouldn't redo it; the reviewer should look at it), else `todo`.
- **Order:** tier 1 = the scenario's `expected_analogs` (Torevia: Latuda, Rexulti, Vraylar, Caplyta, Lybalvi), tier 2 = the other usable analogs in the target's therapeutic area and route group, the ones the finder could pick for it (oral nervous system: 32 more; the route-group rule was added in step 11, before it 36 including 4 sc), tier 3 = the rest. Within a tier, by `analog_id`, then field in `EVIDENCE_FIELDS` order. With no scenario, everything is tier 3.
- **`expected_analogs`** is a new optional top-level key in a scenario YAML (the analogs the team expects, from docs/example_drug.md). Only the queue reads it; the finder doesn't, so it can't steer a ranking.

Open questions:
- Company sources beyond Torevia's 5 analogs: added one by one as the queue reaches each analog whose company isn't SEC-registered (mostly Japanese and European companies). Decides: whoever runs that batch.
- Month-only launch dates (Rexulti, Latuda): enough for the launch quarter, which is all the pipeline uses. Decides: step 11 owner (store `2015-08` vs a day).

Done when: tests show an unlisted URL and a redirect to an unlisted host both refused ✅ (`tests/test_sources.py`); `python -m analog_finder.research.queue --analogs latuda_oral` lists its 4 fields ✅.
